# WORKZEN — Phase 6: Master Organization Management Visual Specifications
## Organization Management & Multi-Tenancy Catalog

---

## 1. Visual Direction & Architecture Benchmarks

The Phase 6 Organization Management experience incorporates 4 distinct enterprise benchmarks:
1. **Mixpanel / Sassy Split-Screen Onboarding:** Crisp left-hand registration card with data residency pills (Nigeria, United States, Europe), domain auto-join toggle, and right-hand 3D isometric cloud graphic.
2. **B2B Floating Popover Switcher:** Dropdown workspace selector anchored to the navigation header, search bar, active organization with vibrant amber-gold gradient highlight and `"Current"` pill, and bottom links (`+ Create New Organization`, `Organization Settings`).
3. **Reem Hospital Call Center SaaS Overview:** 2-column layout featuring left telemetry card (avatar, Org ID `#409283905`, Active status pill, storage & API quota progress bars, Private Multi-Tenant VPC tag), right details form, full-width enable/disable toggle card, and full-width danger zone delete card with 60-day soft archival notice.
4. **Zuper Mobile Application List:** Mobile organization cards displaying company logo, work email, customer/member count, geographical location tag, and active/inactive status badges.
